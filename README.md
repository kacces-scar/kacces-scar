### 🪐 关于这里

你好，我是 **kacces-scar**，欢迎来到我的小小实验室。

这里记录工程探索、动手实验，以及从一个想法到下一次迭代的过程。比起只展示最后的结果，我也想留下「它是怎么一步步变成这样的」。

🛠️ **动手做** — 让想法有一个可以研究和改进的版本。  
🔬 **多试一次** — 记录方案、比较差异、继续迭代。  
🌱 **保持好奇** — 在实践中学习，也在这里分享过程。
